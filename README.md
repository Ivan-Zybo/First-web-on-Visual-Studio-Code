# 🚀 Personal Introduction Page

Страница-визитка веб-программиста и разработчика на Python с пиксельной графикой, космическими элементами и списком любимых фильмов и сериалов.

🔗 **Демо сайта:** [myintroductionxoigt.netlify.app](https://myintroductionxoigt.netlify.app/)

---

### ✨ Что на странице
* **Приветственный блок** — информация об авторе, ссылка на GitHub и космические иллюстрации (`Planet.png`[cite: 3], `stars.png`[cite: 5]).
* **О себе** — гифка, список любимых фильмов/сериалов и космический фон (`Rocketbackground.jpg`[cite: 4]).

### 🛠 Стек технологий
* **HTML5** — структура страницы.
* **CSS3** — позиционирование, фоны и типографика.
